Proyecto Final Marcelo Rey

Descripción:

Este proyecto es una página web de productos y servicios para la entrega final del curso Front-End JS.

Dicha página se encuentra conformada con HTML, CSS Y JavaScript, utilizando una estructura semántica con las etiquetas '<header>', '<nav>', '<aside>',<main>', '<section> y '<footer>', a los fines de organizar el contenido.

Implementa prácticas que mejoran la experiencia del usuario y optimiza la página para los motores de búsqueda.

El contenido es el siguiente:
- Barra de navegación.
- Secciones: Inicio, Servicios (subsecciones: Formación y Aprendizaje, Clases Prácticas de Yoga, Terapias Holísticas y Rituales y Espacios Sagrados), Productos (venta de los mismos mediante un carrito de compras), Acerca de Mí, Reseñas y Contacto.

Se estructuró una página responsiva, en CSS, mediante media queries con puntos de quiebre en 600px, 768px y 1024px.También se utilizó Flexbox y Grid.
La barra de navegación, a partir del punto de quiebre de 768px, es deltipo "hamburguesa".

En JavaScript se implementó:
-Menú Hamburguesa.
-Renderizado de productos en tarjetas con imágen, título, descripción y precio.
- Carrito de compras dinámico con contador dinámico de productos.
- Alamecenamiento en el LocalStorage.

El formato de entrega es mediante un repositorio en GitHub.
